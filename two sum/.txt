problem Statement:
Given an array of integers nums and an integer target, return the indices of the two numbers such that they add up to target.

You may assume that each input has exactly one solution, and you cannot use the same element twice.

Example:
nums = [2,7,11,15], target = 9
Output: [0,1]
----------------------------------------------------
core Idea:
Use a hash map to store each number and its index.

For every nums[i]:

Calculate the number needed:
need = target - nums[i]
Check if need already exists in the hash map.
If it exists, return its stored index and i.
Otherwise, store nums[i] with its index.

-----------------
Example:

nums = [2,7,11,15], target = 9

i=0 → 2 → need=7 → not found → store 2:0
i=1 → 7 → need=2 → found at index 0

answer = [0,1]

Time: O(n)
Space: O(n)
